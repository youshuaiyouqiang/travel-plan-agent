## 跨计划约束

- 保持 `/api` 兼容层，新增契约优先放在 `/api/v1`。
- 每个用户拥有的资源必须由应用服务执行对象级授权；未授权统一返回 404。
- 不接受客户端提供的文件系统路径；本期相册与照片文件服务全部下线。
- 不保存原始论文草稿、新闻全文或用户长期认证令牌。
- 新增 Python 代码使用 Python 3.11 内置泛型、UTC 时间与 Pydantic v2；新增 DTO 默认 `extra="forbid"`。
- 新增前端代码不得新增 `any`、未使用导入或 ESLint 禁用注释。
- 每个任务先写失败测试，再写最小实现，再运行目标测试。
