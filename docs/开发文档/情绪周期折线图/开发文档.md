# 情绪周期折线图开发文档

> **版本：** v1.0，2026-08-03
>
> **状态：** 设计阶段，待评审

## 1. 设计理念

### 1.1 核心洞察

情绪周期不是一条可以线性量化的"温度线"，而是**赚钱效应的扩散与收敛周期**。

- **涨停只是赚钱风格的一种**——短线打板风格
- **趋势也是赚钱风格的一种**——中长线趋势风格
- **资金本质上在模仿追逐已验证的赚钱效应**——哪种风格在赚钱，资金就涌入哪种风格

因此，追踪情绪周期的关键不是"涨停数有多高"，而是"**赚钱效应是否在扩散**"。

### 1.2 不变的东西

市场风格在变（打板、趋势、低吸轮替），但资金行进路线永远不变：

```
赚钱效应出现 → 资金模仿追逐 → 模仿过度饱和 → 利润衰减撤退 → 寻找新方向 → ...
```

这个循环结构就是"不变的东西"。可视化要展现的正是这个循环。

### 1.3 三个风格共生/竞争

市场可以同时存在多种赚钱风格，它们之间可能是**共生**（一起涨一起跌）或**竞争**（资金从一个流向另一个）关系：

- 打板赚钱 + 趋势赚钱 = 全面主升
- 打板赚钱 + 趋势不赚 = 结构性行情（游资主导）
- 打板不赚 + 趋势赚钱 = 蓝筹行情（机构主导）
- 打板不赚 + 趋势不赚 = 全面退潮

通过同时观察三个风格的折线，可以一眼看出共生还是竞争。

## 2. 三条折线图设计

用户要求在一张图表上放置三条折线。**核心：情绪周期是一条连续的线，不是一个点**——只有把每日得分连成折线，才能看出"赚钱效应扩散 → 饱和 → 衰退 → 冰点 → 修复"的周期性起伏。阶段标签只是辅助标注，折线本身才是主体。

| 折线 | 名称 | 数据源 | 含义 |
|------|------|--------|------|
| 全局 | 情绪周期 | 打板 + 趋势 + 反包等权合成 | 总体情绪周期 |
| 短线 | 打板风格 | 打板风格得分 | 短线情绪 |
| 趋势 | 趋势风格 | 趋势风格得分 | 趋势情绪 |

**反包风格不单独画线**，而是融入全局情绪周期（等权参与合成）。这样三条线就能清晰展示短线和趋势的共生/竞争关系。

**折线渲染要点**：
- **全局线按阶段分段着色（核心）**：每个交易日的全局得分点带一个阶段编码，连接到下一日的线段用该日起始阶段的颜色绘制。下跌阶段用绿/蓝、上涨阶段用红、高潮用紫——与 A 股"红涨绿跌"直觉一致，周期起伏一眼可见：
  - 冰点 → 深蓝（最深跌）；强分歧 → 深绿（急跌）；弱分歧 → 浅绿（缓跌）
  - 弱修复 → 浅红（缓涨）；强修复 → 深红（急涨）；高潮 → 紫（过热峰）
  - 线段形状（陡峭/平缓、长短）由真实得分变化决定，颜色编码阶段标签，两者天然吻合：急跌段必落在分歧/冰点色，急涨段必落在修复色。
- 三条线均为 `type: 'line'`，`connectNulls: true`——任一风格某日得分为 None 时连线不断开（None 点跳过，前后直接相连），保证周期曲线视觉连续。
- 横轴严格按交易日排序、等间距排布，非交易日不留空隙，使周期波形不被周末打断。
- 全局线用粗线（width 3.5）突出"周期主线"；打板/趋势用细线（width 1.5）固定色（橙/青）作对照，**不参与阶段着色**。
- **不使用背景色带**：阶段信息已由线段颜色承载，再加背景色带会喧宾夺主；仅在右侧标注当前阶段 + 得分作辅助。

## 3. 赚钱效应指标体系

### 3.1 一阶指标（赚不赚）

度量"当前这个风格是否在赚钱"。

| 风格 | 一阶指标 | 数据源 | 计算方式 | 现状 |
|------|---------|--------|----------|------|
| **打板** | 昨日涨停今日溢价 | `limit_stocks_daily` + `stock_daily` | 取昨日所有涨停股（不含 ST），算今日平均涨跌幅 | **字段存在但未计算（None）** |
| **趋势** | 成交额前 20 平均涨幅 | `top20_volume_avg_chg` | 已有 | ✅ 已计算 |
| **反包** | 断板反包成功率 | `rebound_success_ratio` | 已有 | ✅ 已计算 |

### 3.2 二阶指标（跟风增减）

度量"资金是否在跟进模仿"。窗口 = 3 日，统一用**首末差值**（今日值 − 3 日前值）。3 日窗口只有 3 个点，线性回归易过拟合且意义不大，首末差值更直观、计算更轻、不依赖 numpy。

| 风格 | 二阶指标 | 数据源 | 计算方式 | 现状 |
|------|---------|--------|----------|------|
| **打板** | 涨停数 3 日变化 | `limit_up_count` 今日 vs 3 日前 | 首末差值 | 需新增计算 |
| **趋势** | 上涨家数 3 日变化 | `adv_count` 今日 vs 3 日前 | 首末差值 | 需新增计算 |
| **反包** | 反包成功率 3 日变化 | `rebound_success_ratio` 今日 vs 3 日前 | 首末差值 | 需新增计算 |

### 3.3 昨日涨停今日溢价（关键缺口）

**计算方式**（用户确认）：

```
1. 从 limit_stocks_daily 取昨日 trade_date 的所有 limit_type='up' 记录
2. 过滤掉 ST 股（stock_name 含 'ST' 或 '退'）
3. 取剩余 stock_code 集合
4. 从 stock_daily 取今日 trade_date 这些 stock_code 的 pct_chg
5. 取算术平均值 = yesterday_limit_up_today_premium
```

**边界处理**：
- 昨日无涨停股（涨停数 = 0）→ 返回 `None`（冰点期无法计算溢价）
- 今日 stock_daily 缺失部分代码 → 只算能查到的，全部缺失返回 `None`
- ST 过滤复用 `domain/stock/heuristics.py` 的 `is_st_stock()` 函数

## 4. 风格得分计算

每个风格计算 0-100 的得分，由一阶（60%权重）和二阶（40%权重）合成。

### 4.1 打板风格得分

```python
# 一阶：昨日涨停今日溢价，典型范围 -5% ~ +5%
board_first = yesterday_limit_up_today_premium  # 可能为 None
board_first_norm = clamp((board_first + 5) / 10 * 100, 0, 100)  # -5→0, 0→50, +5→100

# 二阶：涨停数 3 日首末差值，典型范围 -20 ~ +20
board_second = limit_up_count - limit_up_count_3d_ago  # 今日 − 3 日前
board_second_norm = clamp((board_second + 20) / 40 * 100, 0, 100)

# 合成
board_score = 0.6 * board_first_norm + 0.4 * board_second_norm
```

**降级策略**：`yesterday_limit_up_today_premium = None` 时，一阶用 `limit_up_count` 近 20 日分位数替代（复用已有 `compute_limit_up_percentile`），二阶不变。

### 4.2 趋势风格得分

```python
# 一阶：成交额前 20 平均涨幅，典型范围 -3% ~ +3%
trend_first = top20_volume_avg_chg  # 可能为 None
trend_first_norm = clamp((trend_first + 3) / 6 * 100, 0, 100)

# 二阶：上涨家数 3 日首末差值，典型范围 -500 ~ +500
trend_second = adv_count - adv_count_3d_ago  # 今日 − 3 日前
trend_second_norm = clamp((trend_second + 500) / 1000 * 100, 0, 100)

# 合成
trend_score = 0.6 * trend_first_norm + 0.4 * trend_second_norm
```

**降级策略**：`top20_volume_avg_chg = None` 时，一阶用 `adv_decl_ratio` 归一化替代。

### 4.3 反包风格得分

```python
# 一阶：反包成功率，范围 0 ~ 1
rebound_first = rebound_success_ratio  # 可能为 None
rebound_first_norm = rebound_first * 100  # 0→0, 0.5→50, 1→100

# 二阶：反包成功率 3 日变化，典型范围 -0.3 ~ +0.3
rebound_second = rebound_success_ratio_today - rebound_success_ratio_3d_ago
rebound_second_norm = clamp((rebound_second + 0.3) / 0.6 * 100, 0, 100)

# 合成
rebound_score = 0.6 * rebound_first_norm + 0.4 * rebound_second_norm
```

**降级策略**：`rebound_success_ratio = None` 时（如昨日无涨停 / 今日无 stock_daily），反包得分返回 `None`，全局合成时只取打板和趋势的平均。

### 4.4 全局情绪得分

```python
scores = [s for s in [board_score, trend_score, rebound_score] if s is not None]
emotion_score = sum(scores) / len(scores) if scores else 50.0  # 无数据时中性
```

## 5. 阶段判定算法

### 5.1 一阶/二阶 → 阶段映射

核心逻辑：**一阶（得分）判断赚不赚，二阶（动量）判断跟风增减，组合确定阶段。**

- 一阶 = `emotion_score`（0-100）
- 二阶 = `momentum` = 今日得分 − 3 日前得分（`score_3d_ago` 为 None 时动量视为 0）
- 动量阈值 ±5：超过 +5 视为"加速上行"，低于 −5 视为"加速下行"，区间内视为"震荡"

| 得分区间 | 动量（二阶） | 阶段 | 含义 |
|---------|-------------|------|------|
| ≥ 80 | 任意 | **高潮** | 过热区，效应饱和 |
| 60–80 | > 0 | **强修复** | 高位继续扩散（主升） |
| 60–80 | ≤ 0 | **高潮** | 高位见顶 / 减速 |
| 40–60 | > +5 | **强修复** | 中位加速 |
| 40–60 | < −5 | **弱分歧** | 中位回落 |
| 40–60 | [−5, +5] | **弱修复** | 中位震荡偏修复 |
| 20–40 | > +5 | **弱修复** | 低位反弹 |
| 20–40 | < −5 | **强分歧** | 低位续跌 |
| 20–40 | [−5, +5] | **弱修复** | 低位震荡筑底 |
| < 20 | > 0 | **弱修复** | 冰点反弹 |
| < 20 | ≤ 0 | **冰点** | 卖压衰竭但无反弹 |

> **周期闭环**：冰点 → 弱修复 → 强修复 → 高潮 → 弱分歧 → 强分歧 → 冰点。弱分歧 / 弱修复可出现在主升期（中高位震荡）也可出现在退潮期（中低位震荡），这正是用户要找的"变化中不变的东西"。

### 5.2 全局阶段判定

```python
def compute_raw_phase(
    emotion_score: float,        # 全局得分 0-100
    score_3d_ago: float | None,  # 3 日前得分（算二阶动量）
) -> str:
    """判定原始情绪阶段（6 阶段之一，无防抖）。

    返回：冰点 / 强分歧 / 弱分歧 / 弱修复 / 强修复 / 高潮。
    与 §5.1 映射表逐行对应；score_3d_ago 为 None 时动量视为 0。
    """
    momentum = (emotion_score - score_3d_ago) if score_3d_ago is not None else 0.0

    if emotion_score >= 80:
        return "高潮"
    if emotion_score >= 60:
        return "强修复" if momentum > 0 else "高潮"
    if emotion_score >= 40:
        if momentum > 5:
            return "强修复"
        if momentum < -5:
            return "弱分歧"
        return "弱修复"
    if emotion_score >= 20:
        if momentum < -5:
            return "强分歧"
        return "弱修复"
    # < 20
    return "弱修复" if momentum > 0 else "冰点"
```

> **无历史数据降级**：`score_3d_ago is None`（老行 / 冷启动）时动量 = 0，纯按得分粗判——60–80 落"高潮"、40–60 落"弱修复"、20–40 落"弱修复"、<20 落"冰点"。这是预期行为，老数据回填后自动修正。

### 5.3 防抖机制（推迟到 §13）

v1 不实现防抖，阶段直接用 `compute_raw_phase` 的原始输出。原因：防抖的"连续 2 日确认"需要持久化"待确认"状态（新增 `emotion_phase_pending` 列），会让 v025 迁移从 5 列膨胀到 6 列，且首版折线图本身就能通过连续曲线看出周期性，单日抖动在曲线上表现为毛刺而非阶段标签跳变。

防抖作为后续增强放到 §13，届时再评估是否需要。

```python
) -> float | None:
    """计算昨日涨停今日溢价。

    1. 取昨日 limit_stocks_daily 中 limit_type='up' 的记录
    2. 过滤 ST 股（is_st_stock）
    3. 取今日 stock_daily 中这些股票的 pct_chg
    4. 返回算术平均值
    """
    if yesterday is None:
        return None

    yesterday_limit_stocks = deps.select_limit_stocks(yesterday.trade_date)
    if not yesterday_limit_stocks:
        return None

    # 过滤 ST + 只取涨停
    codes = {
        s.stock_code
        for s in yesterday_limit_stocks
        if s.limit_type == "up" and not is_st_stock(s.stock_name)
    }
    if not codes:
        return None

    today_stock_daily = deps.select_stock_daily(trade_date)
    if not today_stock_daily:
        return None

    today_chg_map = {s.stock_code: s.pct_chg for s in today_stock_daily}
    chgs = [today_chg_map[c] for c in codes if c in today_chg_map and today_chg_map[c] is not None]
    if not chgs:
        return None

    return sum(chgs) / len(chgs)
```

| 涨停数 3 日首末差值 | -20 ~ +20 | `(x + 20) / 40 * 100` | 涨停数日波动通常 10-30 |
| 成交额前 20 涨幅 | -3% ~ +3% | `(x + 3) / 6 * 100` | 前 20 平均涨幅波动小于全市场 |
| 上涨家数 3 日首末差值 | -500 ~ +500 | `(x + 500) / 1000 * 100` | A 股约 5000 只，日波动数百 |
| 反包成功率 | 0 ~ 1 | `x * 100` | 直接映射 |
| 反包成功率 3 日变化 | -0.3 ~ +0.3 | `(x + 0.3) / 0.6 * 100` | 成功率日变化通常 < 0.3 |

> **注意**：归一化参数基于 A 股历史经验，后续可根据实际数据分布调整。`clamp` 确保输出在 0-100 范围内。

## 12. 风险与边界

| 风险 | 影响 | 缓解 |
|------|------|------|
| 溢价计算依赖 stock_daily 完整性 | stock_daily 缺失时溢价 None | 降级用涨停数分位数 |
| 反包成功率在冰点期为 None | 反包得分 None | 全局合成时跳过，只取打板+趋势 |
| 阶段判定在得分边界频繁跳转 | 阶段标签不稳定 | v1 不防抖（折线毛刺可接受）；防抖留 §13 |
| 归一化参数不适应极端行情 | 得失偏移 | clamp 限制 + 后续可调参数 |
| 历史 emotion_daily 行无新字段 | 老数据显示 None | 前端降级显示"暂无阶段数据" |

## 13. 后续可扩展方向（不在本次范围）

1. **连板梯度分布**：从 `limit_stocks_daily` 聚合每日各板级家数（1 板几只、2 板几只...），判断梯队健康度
2. **大周期判定**：用 20 日窗口的趋势结构（斜率 + R²）判定主升/退潮/震荡/衰竭
3. **风格切换检测**：打板得分与趋势得分的交叉点，标记风格切换信号
4. **成交额趋势**：`volume_change_pct` 作为辅助维度
5. **跌停数否决**：跌停 > 30 直接降级到冰点/强分歧
6. **阶段防抖（连续 2 日确认）**：新增 `emotion_phase_pending` 列持久化"待确认"状态；`compute_raw_phase` 输出与昨日 confirmed 不同时进 pending，次日 raw 仍为新值才确认切换，否则回退。需 v026 迁移 + `apply_phase_debounce` 纯函数 + fetcher 读昨日 `emotion_phase` / `emotion_phase_pending`。v1 折线图本身已能看出周期性，单日毛刺不影响趋势判断，故推迟。
