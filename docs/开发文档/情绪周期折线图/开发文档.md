# 情绪周期折线图开发文档

> **版本：** v1.0，2026-08-03
>
> **状态：** 设计阶段，待评审

## 1. 设计理念

### 1.1 核心洞察

情绪周期不是一条可以线性量化的"温度线"，而是**赚钱效应的扩散与收敛周期**。

- **涨停只是赚钱风格的一种**——短线打板风格
- **趋势也是赚钱风格的一种**——中长线趋势风格
- **资金本质上在模仿追逐已验证的赚钱效应**——哪种风格在赚钱，资金就涌入哪种风格

因此，追踪情绪周期的关键不是"涨停数有多高"，而是"**赚钱效应是否在扩散**"。

### 1.2 不变的东西

市场风格在变（打板、趋势、低吸轮替），但资金行进路线永远不变：

```
赚钱效应出现 → 资金模仿追逐 → 模仿过度饱和 → 利润衰减撤退 → 寻找新方向 → ...
```

这个循环结构就是"不变的东西"。可视化要展现的正是这个循环。

### 1.3 三个风格共生/竞争

市场可以同时存在多种赚钱风格，它们之间可能是**共生**（一起涨一起跌）或**竞争**（资金从一个流向另一个）关系：

- 打板赚钱 + 趋势赚钱 = 全面主升
- 打板赚钱 + 趋势不赚 = 结构性行情（游资主导）
- 打板不赚 + 趋势赚钱 = 蓝筹行情（机构主导）
- 打板不赚 + 趋势不赚 = 全面退潮

通过同时观察三个风格的折线，可以一眼看出共生还是竞争。

## 2. 三条折线图设计

用户要求在一张图表上放置三条折线：

| 折线 | 名称 | 数据源 | 含义 |
|------|------|--------|------|
| 全局 | 情绪周期 | 打板 + 趋势 + 反包等权合成 | 总体情绪周期 |
| 短线 | 打板风格 | 打板风格得分 | 短线情绪 |
| 趋势 | 趋势风格 | 趋势风格得分 | 趋势情绪 |

**反包风格不单独画线**，而是融入全局情绪周期（等权参与合成）。这样三条线就能清晰展示短线和趋势的共生/竞争关系。

### 2.1 图表布局

```
┌─────────────────────────────────────────────────┐
│  情绪周期 · 07-15 ~ 08-03（共 20 日可浏览）        │
│  当前阶段：强修复    全局得分：62                   │
├─────────────────────────────────────────────────┤
│  高潮  ──────────────────────────────────────────│
│  强修复 ══════════════════════════════════════════│
│  弱分歧 ──────────────────────────────────────────│
│  弱修复 ──────────────────────────────────────────│
│  强分歧 ──────────────────────────────────────────│
│  冰点  ──────────────────────────────────────────│
│                                                   │
│  ─── 全局  ─── 打板  ─── 趋势                    │
│                                                   │
│  [─────────时间轴滑块─────────]                  │

```

- **背景色带**：按 6 阶段分色（冰点深蓝 / 强分歧橙 / 弱分歧黄 / 弱修复浅绿 / 强修复绿 / 高潮红）
- **三条折线**：全局(蓝粗线) / 打板(红细线) / 趋势(绿细线)
- **阶段标注**：右侧标注当前阶段 + 得分
- **底部滑块**：拖动浏览历史（与板块轮动热力图一致）

## 3. 赚钱效应指标体系

### 3.1 一阶指标（赚不赚）

度量"当前这个风格是否在赚钱"。

| 风格 | 一阶指标 | 数据源 | 计算方式 | 现状 |
|------|---------|--------|----------|------|
| **打板** | 昨日涨停今日溢价 | `limit_stocks_daily` + `stock_daily` | 取昨日所有涨停股（不含 ST），算今日平均涨跌幅 | **字段存在但未计算（None）** |
| **趋势** | 成交额前 20 平均涨幅 | `top20_volume_avg_chg` | 已有 | ✅ 已计算 |
| **反包** | 断板反包成功率 | `rebound_success_ratio` | 已有 | ✅ 已计算 |

### 3.2 二阶指标（跟风增减）

度量"资金是否在跟进模仿"。窗口 = 3 日。

| 风格 | 二阶指标 | 数据源 | 计算方式 | 现状 |
|------|---------|--------|----------|------|
| **打板** | 涨停数 3 日趋势 | `limit_up_count` 近 3 日 | 线性回归斜率或首末差值 | 需新增计算 |
| **趋势** | 上涨家数 3 日趋势 | `adv_count` 近 3 日 | 线性回归斜率或首末差值 | 需新增计算 |
| **反包** | 反包成功率 3 日变化 | `rebound_success_ratio` 近 3 日 | 首末差值 | 需新增计算 |

### 3.3 昨日涨停今日溢价（关键缺口）

**计算方式**（用户确认）：

```
1. 从 limit_stocks_daily 取昨日 trade_date 的所有 limit_type='up' 记录
2. 过滤掉 ST 股（stock_name 含 'ST' 或 '退'）
3. 取剩余 stock_code 集合
4. 从 stock_daily 取今日 trade_date 这些 stock_code 的 pct_chg
5. 取算术平均值 = yesterday_limit_up_today_premium
```

**边界处理**：
- 昨日无涨停股（涨停数 = 0）→ 返回 `None`（冰点期无法计算溢价）
- 今日 stock_daily 缺失部分代码 → 只算能查到的，全部缺失返回 `None`
- ST 过滤复用 `domain/stock/heuristics.py` 的 `is_st_stock()` 函数

## 4. 风格得分计算

每个风格计算 0-100 的得分，由一阶（60%权重）和二阶（40%权重）合成。

### 4.1 打板风格得分

```python
# 一阶：昨日涨停今日溢价，典型范围 -5% ~ +5%
board_first = yesterday_limit_up_today_premium  # 可能为 None
board_first_norm = clamp((board_first + 5) / 10 * 100, 0, 100)  # -5→0, 0→50, +5→100

# 二阶：涨停数 3 日趋势，典型范围 -20 ~ +20
board_second = linear_slope([limit_up_count_3d])  # 3 日线性回归斜率
board_second_norm = clamp((board_second + 20) / 40 * 100, 0, 100)

# 合成
board_score = 0.6 * board_first_norm + 0.4 * board_second_norm
```

**降级策略**：`yesterday_limit_up_today_premium = None` 时，一阶用 `limit_up_count` 近 20 日分位数替代（复用已有 `compute_limit_up_percentile`），二阶不变。

### 4.2 趋势风格得分

```python
# 一阶：成交额前 20 平均涨幅，典型范围 -3% ~ +3%
trend_first = top20_volume_avg_chg  # 可能为 None
trend_first_norm = clamp((trend_first + 3) / 6 * 100, 0, 100)

# 二阶：上涨家数 3 日趋势，典型范围 -500 ~ +500
trend_second = linear_slope([adv_count_3d])
trend_second_norm = clamp((trend_second + 500) / 1000 * 100, 0, 100)

# 合成
trend_score = 0.6 * trend_first_norm + 0.4 * trend_second_norm
```

**降级策略**：`top20_volume_avg_chg = None` 时，一阶用 `adv_decl_ratio` 归一化替代。

### 4.3 反包风格得分

```python
# 一阶：反包成功率，范围 0 ~ 1
rebound_first = rebound_success_ratio  # 可能为 None
rebound_first_norm = rebound_first * 100  # 0→0, 0.5→50, 1→100

# 二阶：反包成功率 3 日变化，典型范围 -0.3 ~ +0.3
rebound_second = rebound_success_ratio_today - rebound_success_ratio_3d_ago
rebound_second_norm = clamp((rebound_second + 0.3) / 0.6 * 100, 0, 100)

# 合成
rebound_score = 0.6 * rebound_first_norm + 0.4 * rebound_second_norm
```

**降级策略**：`rebound_success_ratio = None` 时（如昨日无涨停 / 今日无 stock_daily），反包得分返回 `None`，全局合成时只取打板和趋势的平均。

### 4.4 全局情绪得分

```python
scores = [s for s in [board_score, trend_score, rebound_score] if s is not None]
emotion_score = sum(scores) / len(scores) if scores else 50.0  # 无数据时中性
```

## 5. 阶段判定算法

### 5.1 一阶/二阶 → 阶段映射

核心逻辑：**一阶判断赚不赚，二阶判断跟风增减，组合确定阶段。**

| 一阶（赚不赚） | 二阶（跟风增减） | 阶段 | 含义 |
|---------------|-----------------|------|------|
| 强正（>60） | 正且加速 | **强修复** | 效应扩散，资金涌入 |
| 强正（>60） | 正但减速 / 转负 | **高潮** | 效应还在，但跟风见顶 |
| 中正（40-60） | 转负 | **弱分歧** | 效应衰减，跟风撤退 |
| 负（<40） | 负且加速 | **强分歧** | 效应消失，资金出逃 |
| 负（<40） | 负但减速 | **冰点** | 效应已死，但卖压衰竭 |
| 负转正 | 转正 | **弱修复** | 效应初现，资金试探 |

### 5.2 全局阶段判定

```python
def determine_emotion_phase(
    emotion_score: float,        # 全局得分 0-100
    score_3d_ago: float | None,  # 3 日前得分（算二阶）
) -> str:
    """
    返回 6 阶段之一：冰点 / 强分歧 / 弱分歧 / 弱修复 / 强修复 / 高潮
    """
    if score_3d_ago is None:
        # 无历史数据，只按得分粗判
        if emotion_score < 20:
            return "冰点"
        elif emotion_score < 40:
            return "弱修复"
        elif emotion_score < 70:
            return "强修复"
        else:
            return "高潮"

    # 二阶 = 今日得分 - 3 日前得分
    momentum = emotion_score - score_3d_ago

    # 一阶判断
    if emotion_score >= 70:
        # 高分区间
        if momentum > 0:
            return "高潮"       # 还在加速
        else:
            return "高潮"       # 顶部减速，仍算高潮（次日可能转弱分歧）
    elif emotion_score >= 40:
        # 中分区间
        if momentum > 5:
            return "强修复"     # 中分加速
        elif momentum < -5:
            return "弱分歧"     # 中分减速
        else:
            return "强修复"     # 中分稳定
    elif emotion_score >= 20:
        # 低分区间
        if momentum > 5:
            return "弱修复"     # 低分反弹
        elif momentum < -5:
            return "强分歧"     # 低分继续跌
        else:
            return "弱修复"     # 低分稳定
    else:
        # 极低分
        if momentum > 0:
            return "弱修复"     # 冰点反弹
        else:
            return "冰点"       # 仍在冰点
```

### 5.3 防抖机制

为避免单日波动导致阶段频繁跳转，采用**连续 2 日确认**机制：

- 新阶段与前一交易日不同时，标记为"待确认"
- 次日仍为新阶段 → 正式切换
- 次日回到原阶段 → 维持原阶段

### 7.2 修改 `infrastructure/stock/emotion_daily_fetcher.py`

**新增：计算 `yesterday_limit_up_today_premium`**

在 `run()` 函数的韧性计算部分（`_compute_resilience`）附近新增：

```python
def _compute_yesterday_premium(
    trade_date: str,
    yesterday: EmotionIndicators | None,
    deps: _FetcherDeps,
) -> float | None:
    """计算昨日涨停今日溢价。

    1. 取昨日 limit_stocks_daily 中 limit_type='up' 的记录
    2. 过滤 ST 股（is_st_stock）
    3. 取今日 stock_daily 中这些股票的 pct_chg
    4. 返回算术平均值
    """
    if yesterday is None:
        return None

    yesterday_limit_stocks = deps.select_limit_stocks(yesterday.trade_date)
    if not yesterday_limit_stocks:
        return None

    # 过滤 ST + 只取涨停
    codes = {
        s.stock_code
        for s in yesterday_limit_stocks
        if s.limit_type == "up" and not is_st_stock(s.stock_name)
    }
    if not codes:
        return None

    today_stock_daily = deps.select_stock_daily(trade_date)
    if not today_stock_daily:
        return None

    today_chg_map = {s.stock_code: s.pct_chg for s in today_stock_daily}
    chgs = [today_chg_map[c] for c in codes if c in today_chg_map and today_chg_map[c] is not None]
    if not chgs:
        return None

    return sum(chgs) / len(chgs)
```

- 三条折线：全局情绪得分(蓝粗) / 打板风格得分(红细) / 趋势风格得分(绿细)

- 底部时间轴滑块（与 SectorHeatmap 一致的设计）
- 右侧当前阶段标注
- 悬停 tooltip：日期 + 三条线得分 + 阶段

**ECharts 配置要点**：


## 11. 归一化参数汇总

| 指标 | 原始范围 | 归一化公式 | 依据 |
|------|---------|-----------|------|
| 昨日涨停今日溢价 | -5% ~ +5% | `(x + 5) / 10 * 100` | A 股涨停 ±10%，次日溢价极少超 ±5% |
| 涨停数 3 日斜率 | -20 ~ +20 | `(x + 20) / 40 * 100` | 涨停数日波动通常 10-30 |
| 成交额前 20 涨幅 | -3% ~ +3% | `(x + 3) / 6 * 100` | 前 20 平均涨幅波动小于全市场 |
| 上涨家数 3 日斜率 | -500 ~ +500 | `(x + 500) / 1000 * 100` | A 股约 5000 只，日波动数百 |
| 反包成功率 | 0 ~ 1 | `x * 100` | 直接映射 |
| 反包成功率 3 日变化 | -0.3 ~ +0.3 | `(x + 0.3) / 0.6 * 100` | 成功率日变化通常 < 0.3 |

> **注意**：归一化参数基于 A 股历史经验，后续可根据实际数据分布调整。`clamp` 确保输出在 0-100 范围内。

## 12. 风险与边界

| 风险 | 影响 | 缓解 |
|------|------|------|
| 溢价计算依赖 stock_daily 完整性 | stock_daily 缺失时溢价 None | 降级用涨停数分位数 |
| 反包成功率在冰点期为 None | 反包得分 None | 全局合成时跳过，只取打板+趋势 |
| 阶段判定在得分边界频繁跳转 | 阶段标签不稳定 | 连续 2 日确认机制（§5.3） |
| 归一化参数不适应极端行情 | 得失偏移 | clamp 限制 + 后续可调参数 |
| 历史 emotion_daily 行无新字段 | 老数据显示 None | 前端降级显示"暂无阶段数据" |

## 13. 后续可扩展方向（不在本次范围）
