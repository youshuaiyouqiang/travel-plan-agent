# domain/safety/ — 模块记忆

## 职责定位
安全领域层：Prompt 注入防御（输入消毒）基础能力。纯函数实现，无外部依赖，分层干净。

## 关键文件
- `prompt_guard.py`：`PromptGuard`——基于正则的 Prompt 注入模式检测（忽略指令、角色劫持、标签/分隔符注入等）与超长消息截断；只标记不拦截。
- `__init__.py`：包占位。

## 业务边界要点
- 检测到注入仅返回 `warnings` 供上层（`DynamicAgent`/`Orchestrator`）决策并记审计日志，不直接阻断正常内容。
- 消息 >32000 字符判定为可疑载荷并截断。
- 定位为社区版基础防御，不引入第三方 NLP 依赖。
