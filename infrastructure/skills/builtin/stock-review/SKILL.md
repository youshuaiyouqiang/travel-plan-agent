# 股票周期复盘 Skill

## 0. 方法论定位（先读）

**本文是启发式复盘框架，不是硬规则。**

- 所有阈值、判定矩阵、情景推演都来自经验总结，目的是引导 AI 系统化地思考。
- 市场是复杂系统，没有必然规律；任何"如果 X 则 Y"都应该理解为"X 发生时 Y 的概率较高"。
- 多信号冲突时**降低置信度**；异常情况**优先于框架套用**。
- AI 的目标不是"按规则下结论"，而是"用框架辅助分析，让复盘更客观、专业"。

每个 AI 调用工具、查看指标后，问自己：**"现在最可能发生了什么？为什么？"**
而不是"按规则应该判为什么阶段"。

**复盘文末尾必须声明**：本内容仅为基于历史经验的复盘推演，不构成投资建议。

---

## 0.5 分析维度优先级（必读）

**复盘必须按维度优先级展开：大盘 > 板块 > 个股。**

**为什么大盘优先**：
- 大盘连续下跌容易触发**系统性风险**，所有个股都受影响。
- 板块和个股的逻辑在大盘下跌时可能失效（逆势抗跌不代表能在系统性风险中独善其身）。
- 复盘必须**先评估系统性风险等级**，再讨论板块和个股。

**系统性风险等级**（基于大盘维度，仅作参考）：

**重要**：以下阈值为经验性参考，**不是硬规则**。AI 应根据实际情况灵活判断，
大盘连续急跌、多日单日大幅下挫、关键均线失守、市场恐慌情绪蔓延等情境
都可能意味着系统性风险上升。

- **高风险倾向**：大盘**连续多日急跌**、**单日大幅下挫**、**关键均线（如 MA20）失守**等
- **中风险倾向**：大盘**单日小跌**、**缩量阴跌**、市场情绪转弱等
- **低风险倾向**：大盘**平稳或上行**、无明显连续下跌

**对复盘文的约束**：
- "一、周期定位" 应先给出系统性风险等级倾向
- 高风险倾向时，板块高潮、龙头候选的置信度应**降低**
- 高风险倾向时，庄股/抱团股的"独立行情"假设可能失效（系统性风险下无人能独善其身）

## 一、定位与边界

本 skill 教 AI 完成 A 股每日周期复盘。复盘流派为**情绪周期为主 + 大盘趋势辅助**：
短线用涨停/连板/炸板/溢价定节奏（冰点→修复→高潮→分歧→退潮），中线用指数
均线/量能趋势定框架（上升/震荡/下降）。

**数据边界**：
- 数据由后台任务每日 11:30 和 16:30 通过 akshare 抓取，缓存于 SQLite。
- 本 skill 工具**只读缓存**，绝不直接调用 akshare。
- 不提供实时盘中数据；最近一次缓存即为复盘依据。
- 北向资金（已关闭实时数据，2024-08 起），不纳入分析。

**复盘文边界**：
- 观点 + 依据风格：直接给结论，但必须附推理过程和指标依据。
- 必须做明日条件预判：给出基准 + 乐观 + 悲观三种情景及触发条件。
- 末尾必须声明"本内容仅为数据复盘推演，不构成投资建议"。

## 二、核心概念

### 2.1 情绪周期阶段（参考框架，**非离散状态机**）

情绪周期是常见的市场结构，但**不是所有行情都明确按此循环**。
很多时段是"混沌"——信号矛盾，没有明确阶段。

**重要原则**：6 阶段是**概率分布**上的参考点，不是离散的格子。
- **任一阶段次日都可能接任一其他阶段**（冰点/弱修复/强修复/高潮/弱分歧/强分歧/混沌）
- 只是不同接法的**概率高低不同**
- 不存在"必须按循环走"的硬路径
- 框架只描述"现在大概在哪"，不预测"下一步必然去哪"

**典型特征**（仅作参考，AI 须用实际数据验证）：

| 阶段 | 典型特征 | 提醒 |
|------|----------|------|
| 冰点 | 赚钱效应极差，资金不愿接力 | 往往靠近周期底部 |
| 弱修复 | 情绪回暖但力度不强，资金试探 | 需结合连板梯队验证 |
| 强修复 | 赚钱效应明显恢复，上升周期概率高 | 高位需警惕高潮 |
| 高潮 | 情绪极度亢奋 | **高潮通常难以长期持续，连续多日高潮时应警惕顶部** |
| 弱分歧 | 情绪仍高但出现分歧信号 | 与"强修复"边界模糊，靠梯队区分 |
| 强分歧 | 情绪退潮，亏钱效应扩散 | 警惕向冰点演化 |
| 混沌 | 多信号矛盾，框架失效 | 应降低置信度，标注"信号矛盾" |

**阶段转换是概率性的，不是循环的**：

任意阶段次日都可以接**任一其他阶段**（包括同阶段、升级、降级、跳变），
只是概率不同。以下是经验性概率倾向（**仅作参考，不是必然**）：

| 今日阶段 | 次日常见走法（概率较高） | 次日其他可能走法（概率较低） |
|----------|------------------------|----------------------------|
| 冰点 | 弱修复、强修复（连续大跌后的反弹） | 继续冰点、强分歧（恐慌延续）、混沌 |
| 弱修复 | 弱修复延续、强修复（升格）、强分歧（修复失败） | 冰点（修复失败）、高潮（小概率）、弱分歧、混沌 |
| 强修复 | 强修复延续、高潮（升格）、弱分歧（盘中分歧） | 强修复后接任一阶段都可能出现，**任一走法都可能发生，只是概率不同** |
| 高潮 | 高潮后分歧、高潮通常难以长期持续 | 继续高潮（极端行情）、强分歧（高潮崩塌）、混沌 |
| 弱分歧 | 弱分歧延续、强分歧（分歧加大）、弱修复（分歧转修复） | 强修复（强势回流）、冰点（分歧恶化）、混沌 |
| 强分歧 | 强分歧延续、冰点（退潮延续）、弱修复（分歧转修复） | 弱分歧（分歧缓解）、混沌 |
| 混沌 | 矛盾延续，框架失效 | 矛盾缓解，阶段明确 |

**关键提醒**：
- 上升期出现一次"弱分歧"→ 然后"弱修复"→ 继续上升：**完全可能**（不是必然走"弱分歧→强分歧→冰点"）
- 连续大跌后直接"弱修复"或"强修复"：**完全可能**（不一定先"冰点"再"修复"）
- 弱修复次日可以接弱修复/弱分歧/强分歧/强修复中的**任一个**，概率不同
- 强修复次日可以接强修复/弱分歧/弱修复/强分歧中的**任一个**，概率不同
- 框架只描述"现在大概在哪"，不预测"下一步必然去哪"

**不要做的事**：
- 不要把 6 阶段当成必须按循环走的硬路径
- 不要因为"修复失败回冰点"概率高，就忽略"弱修复后接弱分歧"的实际可能
- 不要为了套框架而硬选一个阶段（数据矛盾时选"混沌"）
- 不要把"冰点"和"顶部"混为一谈
- 不要把"高潮"等同于"强势"（高潮常是顶部信号）
- 不要忽视框架失效场景（政策驱动、风格切换、新制度等结构变化）

### 2.2 观察池（多类别候选池）

观察池不是单一池，而是**多类别候选池**。不同类型的股票成为下一轮行情核心的概率和路径不同。

**入池类别**（按类别 1→5 顺序）：

1. **板块分歧后抗跌股**（板块龙头候选）
   - 触发：某板块在高潮分歧后转跌，部分股票**逆势抗跌**
   - 验证：入池次日能否带领板块回流
   - 注：是否成为"主升二龙头"由市场决定，方法论不预判路径

2. **大盘抗跌板块的龙头股**（板块龙头 = 抗跌个股）
   - 触发：大盘下跌时，**板块整体抗跌**（板块跌幅显著小于大盘）
   - 龙头识别：**组合判定**（取前 2，不是交集）
     - **跌幅最小**：板块内跌幅最小的股票
     - **跌幅最大**：板块内涨幅最大的股票
     - 取两者前 2 名（交集经常为空，前 2 更稳健）
   - 这个龙头股同时是个股抗跌股，只是从板块视角看更精准

3. **大盘抗跌个股**（独立候选）
   - 触发：大盘显著下跌时，**个股跌幅显著小于大盘**（具体倍数关系不固定，凭经验）
   - 注：板块未抗跌时的"个股抗跌"——可能是独立行情

4. **新周期信号股**（新周期龙头候选）
   - 触发：连续大跌后首根**显著放量阳线**（放量幅度凭经验判断），
     涨幅靠前的股票

5. **庄股/抱团股**（独立行情，跟踪其独立走势）
   - 特征：与大盘/板块相关性低，关联股票同涨同跌
   - 路径：不跟大盘、不带板块，独立走自己的
   - **仅周复盘识别**（每日复盘不调用相关工具）

**出池条件**（经验性，灵活判断）：股票**持续多日**显著跌破关键均线（如 MA10）→ 触发考虑出池。
不是机械的"2 日就出"，而是综合判断跌破程度、幅度、持续性。

**观察池的周期意义**（经验性判断）：
- 池中多数股票强势走强 → 上升周期确认概率较高。
- 池中股票分化 → 临近分歧概率较高。
- 池中多数股票破位 → 退潮确认概率较高。

**重要提醒**：
- 抗跌股是"下轮龙头候选"，不是"必然龙头"。
- 抗跌股次日验证失败（补跌+不带板块回流）= 抗跌可能是"被动"
  （如停牌、补跌未发生），不应作为龙头候选。
- 入池概率较高不等于必然走强；走弱时果断出池。
- **系统性高风险时，所有类别的置信度统一降低**。

### 2.3 中线趋势框架

用指数（上证/深证/创业板）的均线和量能趋势定中线框架（仅作参考）：

- **上升**：指数站稳 MA20 上方 + 量能环比放大（概率较高）。
- **震荡**：指数在 MA20 附近反复 + 量能不稳定。
- **下降**：指数跌破 MA20 + 量能萎缩或恐慌放量。

中线框架是短线情绪的"背景"（经验性）：
- 上升框架下的分歧可能是买点概率较高。
- 下降框架下的修复可能是卖点概率较高。
- **不是必然**，需结合情绪指标验证。

### 2.4 周期惯性原则（启发式，**与 2.1 节一致**）

情绪周期通常有惯性：阶段连续运行的概率较高。
但**这不是必然**——任何阶段次日都可能跳到任一其他阶段（包括升级、降级、跳变）。

**重要原则**：
- "惯性"指**概率倾向**，不是"必然延续"
- 强修复次日仍有一定概率直接到"强分歧"或"冰点"（惯性被打破）
- 冰点次日仍有一定概率直接"强修复"（V 型反弹，不经过弱修复）
- 框架只描述惯性倾向，不预测"必然延续"

**经验性概率倾向**（仅作参考，AI 须用真实数据验证）：

| 今日阶段 | 次日概率倾向 | 说明 |
|----------|--------------|------|
| 强修复 | 修复延续（至少开盘）概率较高，盘中有高点 | 但仍有概率直接转弱分歧或强分歧 |
| 强分歧/冰点 | 分歧延续（至少开盘）概率较高，盘中有低点 | 但仍有概率直接弱修复或强修复（V 反弹） |
| 弱修复 | 弱修复延续或强化为强修复概率较高 | 但仍有概率直接分歧或回冰点 |
| 高潮 | 高潮后分歧概率较高（高潮难持续 >2 日） | 极端行情下仍可能延续高潮 |
| 弱分歧 | 分歧延续或加大概率较高 | 但仍有概率转修复（弱修复或强修复） |

**对复盘文的约束**：
- 条件预判应给出"概率最高的走法"作为基准情景
- 乐观/悲观是偏离基准的方向，**但不否定其他走法的可能**
- 应明确说明"基准情景是经验性概率倾向，非必然"
- 实际走势与基准偏离时，标注"异常信号"，**优先关注原因而非套框架**
- 不要把"惯性"理解为"必然"——极端事件会让惯性失效

**对条件预判的修正**：
- 之前 v3 的预判矩阵是"基准=今日延续"，**但实际不是必然延续**
- 改进为：基准 = "今日阶段惯性走法"（概率最高），但同时给出其他可能走法
- 避免给读者"明日必然如何"的错觉

## 三、复盘思维链（7 步详解）

**必须按顺序执行，每一步的输出是下一步的输入。**
每步完成后自检：是否有信号矛盾？是否需要标注"混沌"或"框架失效"？
**所有结论必须先通过"大盘维度"的系统性风险等级过滤**。

### 第 1 步：定大盘基调（最高优先级）

**目的**：判断今天是强的一天还是弱的一天，并评估系统性风险等级。

**看什么**（调 `get_market_snapshot(date)`）：
- 三大指数涨跌幅：上证 / 深证 / 创业板
- K 线形态：阳线 / 阴线 / 十字星 / 长上影 / 长下影
- 量能：两市成交额，与昨日环比
- 大盘连续下跌天数

**判断启发**（非硬规则）：
- 三大指数同步上涨 + 放量 → 强势概率较高
- 三大指数同步下跌 + 缩量 → 弱势概率较高
- 指数分化（如上证涨创业板跌）→ 需看情绪指标定调
- 长上影 + 放量 → 冲高回落，偏弱概率较高
- 长下影 + 缩量 → 探底回升，偏强概率较高

**系统性风险等级评估**（**仅作参考**，具体阈值凭经验）：
- 高风险倾向：连续多日急跌 / 单日大幅下挫 / 关键均线失守
- 中风险倾向：单日小跌 / 缩量阴跌
- 低风险倾向：平稳或上涨

**输出**：今日大盘基调 = [强势/弱势/分化]，量能 = [放量/缩量]X%，
系统性风险等级 = [高/中/低]

### 第 2 步：定情绪阶段（参考框架，受大盘维度过滤，**看趋势不是看截面**）

**目的**：判断当前情绪阶段的概率倾向（不是硬判定）。

**重要原则（与可视化深度耦合）**：

**情绪周期是"阶段性的"，不是固定阈值的**。
- **主升期**（整体环境热）：涨停家数多、溢价强、连板高——即使出现一次弱分歧，涨停家数依然可能 50+
- **退潮末期**（整体环境冷）：即使强修复，涨停家数可能只有 30-40（远低于主升期的"强修复"）
- **连续大跌中的高潮**：几乎不可能出现
- **用固定阈值（如"涨停数 <30 = 冰点"）跨周期判定是不合理的**

→ **AI 必须看"多天连起来的趋势"，不是单日截面**。
→ **这就是为什么需要图表**——图表不仅是给用户看的，更是**给 AI 提供趋势数据**的。
→ AI 看的应该是"**多日**的涨停家数曲线 + 炸板率曲线 + 连板高度曲线"（具体观察窗口凭经验），
而不是"今天的涨停家数 = 50"。

**看什么**（调 `get_emotion_indicators(date)` 返回**多日序列数据**）：
1. **涨停家数曲线**（多日序列，具体观察窗口凭经验）
2. **跌停家数曲线**（多日序列）
3. **有效涨停数曲线**（一次性封死，不含炸板回封）
4. **炸板率曲线**
5. **连板高度曲线**（最高几连板）+ **连板梯队完整性曲线**
6. **昨日涨停今日溢价率曲线**
7. **量能曲线**（两市成交额）

**6 阶段参考矩阵**（**仅作单日截面参考**，跨周期不成立）：

| 阶段 | 涨停数 | 炸板率 | 连板高度 | 梯队 | 昨涨停溢价 | 量能 |
|------|--------|--------|----------|------|------------|------|
| 冰点 | <30 | >50% | ≤2板 | 完整但矮 | 负溢价 | 缩量 |
| 弱修复 | 30-50 | 30-50% | 3板 | 完整 | 微正溢价 | 略放量 |
| 强修复 | 50-80 | <30% | 4板 | 完整 | 正溢价 | 放量 |
| 高潮 | >80 | <20% | ≥6板 | 完整 | 强正溢价 | 放量 |
| 弱分歧 | 50-80 | 20-40% | 4-5板 | 轻微断层 | 正溢价减弱 | 放量滞涨 |
| 强分歧 | 30-50 | 40-60% | 断层 | 明显断层 | 负溢价 | 缩量 |
| 混沌 | 矛盾 | 矛盾 | 矛盾 | 矛盾 | 矛盾 | 矛盾 |

**重要**：上表是**单日截面的参考值**，**不能跨周期套用**：
- 主升期的弱分歧：涨停数可能 50+（因为环境热）
- 退潮末期的强修复：涨停数可能只有 30-40（因为环境冷）
- **必须结合多日趋势曲线判定**

**有效涨停判定**（关键精化）：
- **有效涨停** = 一次性封死
  - `炸板次数 == 0` 且 `首次封板时间 == 最后封板时间`
- **无效涨停** = 上午涨停后炸板下午回封
  - 排除此类股票，不计入"有效涨停"

**组合判定启发**（关键，AI 须结合趋势曲线灵活运用）：
- **涨停数高 ≠ 强**：涨停数虽高但炸板率也高 = 分歧概率较高，不是强。
- **连板高 ≠ 强**：连板虽高但梯队断层 = 虚高概率较高，不是真高潮。
- **趋势向上 = 强**（**多日连续上升**时，概率较高）：涨停数曲线持续上升 + 溢价持续为正 + 炸板率下降 → 上升周期概率较高
- **趋势向下 = 弱**（**多日连续下降**时，概率较高）：涨停数曲线持续下降 + 溢价转负 + 炸板率上升 → 退潮概率较高
- **趋势震荡 = 混沌**：多日数据无明显方向 → 框架失效概率较高
- **跨周期不套用阈值**：主升期的"弱分歧"和退潮末期的"弱分歧"，涨停数可能差异很大

**判定优先级**（启发性，结合趋势曲线）：
1. **先看趋势曲线**（多日序列方向）→ 定大方向（上升/下降/震荡）
2. **再看溢价方向**（正/负）→ 定情绪倾向
3. **再看涨停数 + 炸板率组合**（结合趋势）→ 定强度
4. **最后看连板梯队** → 验证
5. **多日数据矛盾 → 选"混沌"，降低置信度**

**大盘维度过滤**：
- 系统性高风险时，情绪阶段判定置信度**整体降低**
- 涨停数高但大盘连续下跌 → 可能是"虚假强势"（指数弱、个股强）
- 大盘单边下跌时，情绪阶段可能不可靠

**输出**：今日情绪阶段 = [6 阶段之一或"混沌"]，核心依据 = [趋势曲线方向 / 溢价X / 涨停Y / 炸板率Z / 连板W]，
置信度 = [高/中/低]，
**必须附多日趋势数据**（最近 5-10 日关键指标）

### 第 3 步：与历史对比定趋势

**目的**：判断当前是上升、下降还是震荡周期（概率性判断）。

**与昨天比**（调 `get_emotion_indicators(yesterday)`）：

常见阶段切换映射（经验性）：
- 冰点 → 弱修复 = 修复启动
- 弱修复 → 强修复 = 上升加速
- 强修复 → 弱分歧 = 顶部预警
- 弱分歧 → 强分歧 = 退潮确认
- 强分歧 → 冰点 = 持续退潮
- 高潮 → 强分歧 = 顶部转折

**与上一轮退潮比**（调 `get_emotion_indicators` 取最近一次强分歧→冰点段）：

- 找到最近一次"强分歧 → 冰点"的周期
- 对比当前修复力度 vs 上一轮修复力度：
  - 修复力度 = 涨停数恢复速度 + 连板高度回升速度
  - 当前涨停数 > 上一轮首次强修复涨停数 → 上升周期概率较高
  - 当前涨停数 < 上一轮首次强修复涨停数 → 下降周期概率较高
  - 持平 → 震荡周期概率较高
- **注意：历史对比是参考，结构变化时失效**

**输出**：趋势 = [上升/下降/震荡]，对比依据 = [与昨日切换X / 与上一轮修复力度Y]，
置信度 = [高/中/低]

### 第 4 步：看板块轮动 + 板块高潮判定 + 强修复领涨延续验证

**目的**：判断资金是否有主线，轮动节奏是否健康，识别板块高潮信号。

**常规板块分析**（调 `get_sector_rotation(date)`）：
- 领涨板块（涨幅前 5）+ 领跌板块（跌幅前 5）
- 持续性：今日领涨是否延续昨日主线
- 轮动速度：领涨板块切换频率

**判断启发**：
- 主线持续（领涨板块连续 2+ 日领涨）→ 上升期概率较高
- 快速轮动（领涨板块每日切换，一日游多）→ 高潮或分歧概率较高
- 板块齐跌（无领涨）→ 冰点或强分歧概率较高
- 题材联动（多板块同题材共振）→ 强主线概率较高

**板块高潮判定**（概率性判断，**不要求所有条件同时满足**）：

**重要原则**：股市讲的是概率，没有绝对的事情。
下面 3 个条件是**加分项**——满足越多说明板块高潮越真实、置信度越高。
**任一条件缺失都不否定板块高潮**，只是置信度降低；3 个条件都满足也
不构成"必然高潮"。

**特别说明**：下面的具体数值（涨停数、市值、时段占比）都是**经验性参考**，
不是硬规则。AI 应根据市场实际情况灵活判断，不应机械套用。

**条件 1：有效涨停数量**（核心指标）
- 板块内**有效涨停数量较多**为高置信度门槛（具体数量视市场情况而定）
- 有效涨停 = 一次性封死（`炸板次数 == 0` 且 `首次封板时间 == 最后封板时间`）
- **排除**：上午涨停后炸板下午回封（无效涨停）
- 涨停数较少：板块高潮置信度降低，但仍可能处于高潮

**条件 2：发酵均匀**（加分项）
- 把交易日分为多个时段（如：上午、午盘、尾盘，时段划分仅作参考）
- **各时段都有新涨停**（不同时段新出现的有效涨停，不算回封）= 发酵均匀
  → 说明资金在板块高潮中持续接力，可信度更高
- 避免"开盘冲高后熄火"（具体占比阈值不固定，凭经验）
- 若发酵不均匀（如只在上午冲高、午盘熄火）= 板块高潮置信度降低
  但仍可能是高潮（资金选择上午集中拉升也是合理的）

**条件 3：大市值股票参与**（加分项）
- 板块内有**显著市值的龙头股涨停**（市值门槛视市场情况而定，
  约 600 亿为参考值）= 板块高潮更真实（避免小盘股自嗨）
- 若没有大市值股票参与 = 板块高潮置信度降低
  但仍可能是高潮（小盘股主导的高潮也可能是真实的）

**板块高潮判定规则**（概率性）：

| 满足条件数 | 板块高潮置信度 |
|------------|----------------|
| 3 个都满足 | 高置信度（典型板块高潮） |
| 满足条件 1 + 任一其他 | 中置信度（大概率板块高潮） |
| 仅满足条件 1 | 中低置信度（可能是板块高潮） |
| 任一条件都不完全满足 | 低置信度（不否定板块高潮，但不建议据此操作） |

**判定为板块高潮时**：
- 板块情绪极度亢奋概率较高
- 警惕顶部转折（不是必然）
- 关注该板块分歧时点
- **系统性高风险时，板块高潮的可信度降低**（大盘下跌时板块高潮可能是"补涨假象"）

**复盘文必须说明**：
- 满足了多少个条件（明确列出）
- 板块高潮的置信度（高/中/低）
- 哪个条件缺失、为什么仍判定/不判定为板块高潮

**板块分歧识别**：
- 触发：曾判定为"板块高潮"的板块，今日出现：
  - 龙头股**显著下跌**
  - 板块涨幅由正转负
  - 板块内炸板率**显著上升**
- 含义：板块高潮分歧概率较高，关注"分歧后逆势抗跌个股" → 入池（类别 1）
- **具体跌幅阈值、炸板率阈值不固定**，凭经验判断"显著"的程度

**强修复领涨延续验证**（经验性判断）：

**触发条件**：昨日或最近一次是"强修复"阶段。

**验证方法**（调 `get_strong_repair_leaders()`）：
- 取该强修复日的领涨板块 top1-3
- 检查这些板块今日表现：
  - **延续领涨** → 真修复概率较高，主线确立，上升周期确认
  - **切换到其他板块领涨** → 虚修复概率较高，情绪混沌，主线未确立
  - **领涨板块转跌** → 修复失败信号概率较高，警惕退潮

**重要提醒**：
- 延续不是必然：板块切换可能因为新热点、新政策、行业周期变化。
- 一次不延续不必然否定前次强修复，需结合后续走势综合判断。
- 连续 2+ 次强修复后领涨都不延续 → 警惕情绪转弱。

**输出**：板块状态 = [主线持续/快速轮动/齐跌/混沌]，主线 = [板块名或无]，
领涨验证 = [真修复/虚修复/修复失败/不适用]，
板块高潮 = [是/否/不适用] + 判定依据

### 第 5 步：复盘观察池（多类别，含领涨验证）

**目的**：评估池中股票能否成为下轮龙头，通过验证确认情绪。

**看什么**（调 `get_watchlist()` → 对每只调 `get_stock_daily(code, 10)`）：
- 今日涨跌幅 + 是否跑赢大盘
- 累计涨幅（入池至今）
- 是否守住**关键均线**（如 MA10，仅作参考均线） + 距均线偏离度
- 量能变化
- **入池类别**（用于差异化验证）

**逐只评估**（按类别差异化）：

**类别 1：板块分歧后抗跌股**
- 验证方法：查其入池次日板块是否回流
- **领涨 + 板块回流** → 板块龙头概率较高
- **补跌 + 板块继续跌** → 抗跌失败，板块龙头概率低

**类别 2：大盘抗跌板块的龙头股**
- 验证方法：查其入池次日板块表现
- **龙头继续走强 + 板块共振** → 板块龙头确立概率较高
- **龙头补跌 + 板块跟跌** → 抗跌是被动（板块整体抗跌中的伪龙头），不应作为龙头候选

**类别 3：大盘抗跌个股**（板块未抗跌时）
- 验证方法：查其入池次日表现 + 是否带板块回流
- **次日走强** → 可能是独立行情
- **次日补跌** → 抗跌是被动，不应作为龙头候选

**类别 4：新周期信号股**
- 验证方法：查其入池后 2-3 日的延续性
- 延续走强 → 上升周期确认概率较高
- 不延续 → 虚信号概率较高，情绪混沌

**类别 5：庄股/抱团股**
- 独立跟踪，不参与板块主升判断
- 重点看累计涨幅是否持续，量能是否稳定

**池整体状态判定**：
- **类别 1 验证通过率高** → 板块龙头确认概率较高
- **类别 2 验证通过率高** → 上升周期概率较高
- **类别 3 验证通过率高** → 独立行情活跃
- **类别 5 持续走强** → 庄股/抱团行情
- **多类别同时走强** → 全市场情绪强
- **多类别同时走弱** → 全市场情绪差
- **系统性高风险时，池整体状态判定置信度降低**

**出池规则**（经验性，灵活判断）：
- 股票**持续多日**显著跌破关键均线 → 触发考虑出池
- 抗跌验证失败 + 累计跌幅**显著** → 标记"弱势"，逼近出池
- **具体跌破天数、跌幅阈值不固定**，凭经验综合判断

**输出**：观察池状态 = [多数强势/分化/多数破位/验证失败]，重点标的 = [代码1/代码2]，
池整体验证倾向 = [确认上升/混沌/确认退潮]

### 第 6 步：扫描新信号（多类别）

**目的**：识别今日是否有新的入池信号（概率性筛选）。

**抗跌股扫描**（调 `get_signal_stocks(date)`）：
- 触发：大盘**显著下跌时**（具体跌幅阈值不固定，凭经验判断）
- 筛选：个股**跌幅显著小于大盘**（具体倍数关系不固定，凭经验判断）
- 记录：入池原因 = resistant，入池价 = 今日收盘，入池大盘点位

**抗跌板块扫描**（调 `get_resistant_sectors(date)`）：
- 触发：大盘**显著下跌时**（具体跌幅阈值不固定）
- 筛选：板块**跌幅显著小于大盘**（具体倍数关系不固定）
- 进一步：板块内涨停数较多 或 逆势上涨股票较多
- 输出：抗跌板块清单
- 提取龙头股（调 `get_sector_leaders(板块名)`）：
  - **跌幅最小 + 涨幅最大组合**（取两者前 2，不是交集）
  - 同时满足两个条件的股票权重最高
  - 仅满足一个条件的股票作为次级候选
  - 入池（类别 2）

**板块分歧后抗跌股扫描**（调 `get_sector_divergence(date)`）：
- 触发：曾判定为"板块高潮"的板块，今日分歧
- 筛选：板块内个股跌幅**显著小于板块整体跌幅**（具体倍数关系不固定）
- 提取：分歧后抗跌个股 → 入池（类别 1）
- 记录：入池板块、入池板块所处阶段（高潮分歧）

**新周期信号股扫描**（调 `get_signal_stocks(date)`）：
- 触发：连续多日下跌后今日出现**显著放量阳线**（量比、阳线实体等具体阈值不固定）
- 筛选：今日涨幅靠前的股票
- 记录：入池原因 = breakout，入池价 = 今日收盘，入池大盘点位

**庄股/抱团股识别**（调 `get_correlation()`，**周复盘模式，每日复盘不调用**）：
- 仅在用户明确要求"周复盘"或自定义指定时调用
- 识别：与大盘/板块相关性 < 0.3 的股票
- 聚类：找出相互高度相关（>0.7）的多只股票 → 抱团股群
- 入池：单只庄股或抱团股群中代表股 → 类别 5
- 每日复盘时，庄股/抱团股池内的股票不参与板块主升判断

**重要提醒**：
- 入池是"候选"不是"推荐"——候选股票成为龙头的概率较高，但非必然。
- 抗跌股补跌时果断出池，不要因为"入池了就一定要涨"而抗单。
- 入池后第二天就应开始验证，验证失败的及时调整。
- **系统性高风险时，新入池股票的优先级降低**（风险偏好收缩）。

**输出**：今日新信号 = [抗跌X只 / 抗跌板块Y个+龙头Z只 / 板块分歧后抗跌M只 / 新周期N只]，
入池清单

### 第 7 步：综合研判 + 条件预判

**目的**：整合前 6 步，产出周期定位、趋势判断和明日情景推演（概率性）。

**综合周期定位**：
- 短线情绪阶段（第 2 步）+ 中线趋势框架（第 3 步）+ 观察池状态（第 5 步）
- 三者共振 → 高置信度判断
- 三者矛盾 → 低置信度，标注"信号矛盾"
- **任何判断都要标注置信度（高/中/低）**
- **必须先经过"系统性风险等级"过滤**

**明日条件预判**（必须给出 3 种情景，仅作参考，**非预测**）：

**重要原则**（与 2.1、2.4 一致）：
- 6 阶段是**概率分布**上的参考点，不是离散的格子
- **任一阶段次日都可能接任一其他阶段**，只是概率不同
- 基准情景 = "今日阶段的惯性走法"（概率最高），但**不否定其他走法**
- 不要给读者"明日必然如何"的错觉

**基准情景 = 今日阶段的惯性走法（概率最高）**：

| 今日阶段 | 基准情景（概率较高） | 乐观情景（偏离基准，概率较低） | 悲观情景（偏离基准，概率较低） |
|----------|--------------------|----------------------------|----------------------------|
| 冰点 | 分歧延续，盘中有低点，低点后有修复（大小不确定） | 冰点反转强修复：涨停骤升 50+，炸板率 <30% | 恐慌加速：跌停 >50，放量下跌 |
| 弱修复 | 弱修复延续或强化 | 升格强修复：涨停 50-80，炸板率 <30%，正溢价 | 修复失败回冰点：涨停 <30，炸板率 >50% |
| 强修复 | 修复延续，盘中有高点，盘中可能分歧 | 高潮：涨停 >80，连板 ≥6，强正溢价 | 转弱分歧：涨停回落 50 以下，炸板率升 30%+ |
| 高潮 | 高潮后分歧（高潮难持续 >2 日） | 极端高潮延续：涨停维持 >80 | 高潮崩塌强分歧：涨停骤降，炸板率 >40% |
| 弱分歧 | 分歧延续或加大 | 分歧转强修复：涨停回升 50-80，炸板率降 | 加速强分歧：涨停降，炸板率 >40% |
| 强分歧 | 分歧延续，盘中有低点，低点后有修复（大小不确定） | 分歧转弱修复：涨停回升 30-50，炸板率降 | 加速冰点：涨停 <30，跌停多，缩量 |
| 混沌 | 信号矛盾延续，框架失效 | 矛盾缓解，阶段明确 | 矛盾加剧，进入未知状态 |

**其他可能走法**（不属于乐观/悲观，但确实可能发生）：
- 弱修复 → 弱分歧（修复中分歧，升级为弱分歧而非强分歧）
- 弱修复 → 强分歧（修复失败，直接到强分歧，跳过冰点）
- 强修复 → 强分歧（修复失败，直接到强分歧，跳过弱分歧）
- 强修复 → 弱修复（修复力度弱化）
- 强分歧 → 弱修复（分歧转修复的另一种路径）
- 强分歧 → 强修复（V 型反弹，强势回流）
- **任何"今日阶段 → 次日阶段"的组合都可能出现，只是概率不同**

**重要说明**：
- 上述情景是经验性的概率推演，不是预测。
- 实际走势由市场决定，与基准偏离时优先关注原因。
- 复盘文末尾必须说明"以下为基于历史经验的概率推演，不构成预测"。
- **系统性高风险时，所有情景的概率倾向整体下移**（悲观情景概率上升）。
- **应同时说明"其他可能走法"，避免给读者"只此 3 种"的错觉**。

**应对策略**（每个情景对应）：
- 修复情景 → 关注观察池强势股 + 新信号股
- 延续情景 → 维持当前判断
- 退潮情景 → 防御，关注观察池破位风险
- 其他走法 → 复盘时再调整，不预设策略

**输出**：周期定位 + 趋势 + 明日 3 情景 + 其他可能走法 + 应对策略 + 置信度

## 五、常见误区（AI 必须避免）

1. **只看涨停数**：涨停数高但炸板率也高 = 分歧概率较高，不是强。
2. **忽略量能**：缩量涨停 = 持续性差概率较高；放量涨停 = 资金真实参与概率较高。
3. **连板高度误读**：6 板但 3-5 板断层 = 虚高概率较高，不是真高潮。
4. **把冰点当顶部**：冰点是底部信号概率较高，不是卖出信号。
5. **把高潮当强势**：高潮是顶部信号概率较高，不是追涨信号。
6. **忽略溢价方向**：溢价方向比涨停数更重要，正溢价 = 延续概率较高，负溢价 = 退潮概率较高。
7. **板块轮动误判**：快速轮动 = 资金无主线概率较高，是高潮/分歧信号，不是强势。
8. **观察池误用**：观察池破位 ≠ 立即看空，是退潮信号概率较高；观察池走强 ≠ 立即看多，是上升确认概率较高。
9. **条件预判不具体**：不能写"明日可能涨可能跌"，必须给具体触发条件。
10. **把框架当真理**：6 阶段、阈值、情景矩阵都是经验，不是规律。
    信号矛盾时降低置信度，不要硬选。
11. **忽略方法论边界**：框架适用于"主流情绪周期行情"，不适用于
    政策驱动、风格切换、新制度等结构变化场景。AI 应识别"框架失效"信号。
12. **用绝对措辞**：避免"一定/必然/绝对"，改为"概率较高/偏低/可能"。
13. **忽略大盘维度**：不复盘大盘就先讨论板块和个股——大盘系统性风险下，板块和个股逻辑可能失效。
14. **混淆有效涨停与无效涨停**：把"炸板回封"算作有效涨停会高估板块高潮的真实性。
15. **板块高潮只看涨停数**：忽略"发酵均匀"和"大市值参与"两个必要条件。
16. **庄股/抱团股每日复盘调用**：庄股/抱团股识别仅周复盘调用，每日复盘不应使用。
17. **板块龙头取交集**：跌幅最小+涨幅最大取交集经常为空，应取前 2 名。

## 六、边界情况处理

1. **数据缺失**：若某工具返回空，在复盘文对应章节标注"该维度数据缺失"，
   不臆测。
2. **非交易日（周末/节假日）**：**不要直接用 system_prompt 中的"今天"** 作为
   `trade_date`（拿到空数据）。**先调 `get_latest_trade_date_with_data`**
   拿到最近一个有数据的交易日（YYYYMMDD），**再用该日期作为所有
   `trade_date` 参数**，复盘文标题写"YYYYMMDD 复盘"而非"今日复盘"。
   缓存完全无数据时工具返 `latest_trade_date: null`，此时回退到"框架性
   复盘"模式并说明"暂无缓存数据"。
3. **极端行情**：千股跌停/涨停等极端情况，跳出框架，单独说明。
4. **新股次新**：观察池排除上市 <60 日的新股（波动大，不代表情绪）。
5. **停牌**：观察池股票停牌时，标注"停牌"，不触发出池。
6. **信号矛盾**：当情绪指标与大盘/观察池矛盾时，标注"信号矛盾"，
   降低置信度，不强行给结论。
7. **框架失效**：当出现政策窗口、风格切换、新制度等结构变化时，
   主动标注"框架可能失效"，不强行套用 6 阶段。
8. **数据可信度**：akshare 数据源可能延迟或缺失，AI 应在复盘文末尾说明
   "数据来源为 akshare，存在一定延迟"。
9. **系统性高风险倾向**：大盘连续多日急跌或单日大幅下挫时，所有判断置信度
   整体降低，标注"系统性风险下，框架有效性降低"。
   **不要求连续 ≥3 日或单日跌幅 ≥2% 才算高风险**，凭经验综合判断。
10. **板块高潮但大盘下跌**：警惕"补涨假象"——大盘系统性下跌时板块高潮
    可能是最后的疯狂，板块高潮可信度降低。

## 七、工具调用顺序与策略

**严格按以下顺序调用**（每一步的输出是下一步的输入）：

**Step 0（前置条件，Task 18）**：`get_latest_trade_date_with_data()` → 取最近一个有数据的交易日（YYYYMMDD）
- **触发条件**：今天是周末（周六/周日）或法定节假日（春节/国庆等）
- **判断依据**：system_prompt 顶部 "📅 今天是YYYY年M月D日，星期X" 的"星期X" + 节假日常识
- **如果今天就是交易日**：仍可调一次确认（或直接用今天），但**强制使用工具返回值作为后续 trade_date**，不要凭印象写
- **如果工具返回 null**：缓存完全无数据，进入"框架性复盘"模式，复盘文标注"暂无缓存数据"

后续步骤 1-13 的 `date` 参数统一使用 Step 0 返回的 YYYYMMDD：

1. `get_market_snapshot(date)` → 第 1 步大盘基调（含系统性风险等级）

8. `get_sector_leaders(板块名)` → 第 4 步提取抗跌板块龙头（如适用）
9. `get_sector_divergence(date)` → 第 4 步板块分歧识别（如适用）

11. 对池中每只股票 `get_stock_daily(code, 10)` → 逐只评估
12. `get_signal_stocks(date)` → 第 6 步抗跌股/新周期信号股扫描
13. 综合研判 + 条件预判 → 第 7 步产出复盘文

**周复盘额外调用**（用户明确要求"周复盘"时）：

**调用优化**：

- `get_correlation()` 仅在用户明确要求"周复盘"或自定义指定时调用。

## 九、红线

- **不预测具体涨跌**：只做周期阶段评判和结构性观察，不给"明天必涨/必跌"结论。
- **不构成投资建议**：复盘文末尾必须声明。
- **不编造数据**：数据缺失时如实说明，不臆测。
- **不跳过步骤**：7 步必须完整执行，即使某步数据缺失也要在复盘文中体现。
- **不做绝对判断**：用"概率较高""可能"等措辞，不用"一定""必然""绝对"。
- **不混淆主次**：溢价方向 > 涨停数+炸板率组合 > 连板梯队。
- **不忽视框架失效**：遇到政策窗口、风格切换等结构变化，主动标注并降低置信度。
- **不忽略大盘维度**：系统性风险等级是最高优先级，必须先评估。
- **不混淆有效/无效涨停**：板块高潮判定必须用有效涨停（一次性封死）。
- **不混淆庄股/抱团股调用时机**：仅周复盘或用户明确指定时调用。
- **不只看单日截面**：必须看多日趋势曲线，跨周期不套用固定阈值。
- **工具必须返回多日序列数据**：不仅是当日快照，AI 看的应该是"曲线"而非"点"。
